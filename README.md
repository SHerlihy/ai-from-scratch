# ai-from-scratch

## Description

A GPT-like large language model created by me from byte-pair encoding to supply tokenized data to fine-tuning to follow human instruction.

## Motivation

> "You don't have to be an engineer to be a racing driver, but you do have to have Mechanical Sympathy."
>
> — Sir Jackie Stewart

I already was starting to create AI enabled web appplications before I decided to dive deep on how LLMs work.
While creating my applications I discovered Prompt Engineering and I had to create strategies to minimize hallucinations amoungst other issues and challenges novel to working with AI.
I have been successful in creating my AI applications, however, like any novel technology it is improtant to understand it's limitations and strengths.
This is why I decided to create my own LLM.
